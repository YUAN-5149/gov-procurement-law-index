# 政府採購法令彙編 · 學習索引網站

## 開啟方式
- 雙擊 `index.html`（需 data.js、app.js 在同資料夾）
- 或使用 `政府採購法令彙編-單檔版.html`（全部內嵌，可單獨複製到隨身碟或手機）
- `圖解總表.html`：九張流程圖的單頁版，可直接列印（每張圖不會被切斷）

## 功能

### 搜尋
- **關鍵字**：跨全部法規全文比對，命中標黃，結果依法規分組
- **多關鍵字**：空白分隔即 AND，如 `異議 申訴 期限`
- **條號直達**：輸入 `50`、`第50條`，列出各法規同條號條文
- **範圍限縮**：全部法規／本法規／本分類／★我的重點
- 快捷鍵：`Ctrl+K` 或 `/` 聚焦、`Esc` 清除

## 資料來源與注意事項

- **法律與法規命令**：全國法規資料庫（法務部）`law.moj.gov.tw`
- **工程會行政規則**：行政院公共工程委員會主管法規共用系統 `lawweb.pcc.gov.tw`
- 兩者皆為擷取當日之現行有效版本，擷取日期見網站首頁
- **速記卡、概念比較、GPA 導讀、選擇題為學習用整理與自製練習題**，非法規原文亦非官方考古題；金額與期限請以最新法規及主管機關公告為準
- **已排除**：已廢止或停止適用之法規（採購文件保存作業準則、機關辦理工程委託專案管理廠商評選及計費辦法、採購履約爭議調解暨收費規則等）
- **函頒文件**：「政府採購錯誤行為態樣」取自政府電子採購網解釋函令系統之 113.12.05 函附件（.docx），以 `tools/planpe_dl.py` ＋ `tools/docx_read.py` 抓取解析
- **錯誤行為態樣家族**：工程會共函頒 13 份，其中 5 份具文字層已收錄；**§22各款執行錯誤態樣、評分及格最低標、共同供應契約缺失態樣之附件為掃描影像 PDF**，此環境無 OCR 故未收錄；最有利標與統包兩份實為「作業手冊」而非態樣表，性質不同未納入
- **解釋函令**：僅收錄**索引**（主旨摘要、發文日期與字號、對應條號），不含全文；主旨在來源即為節錄，過長者於 100 字截斷。該系統需瀏覽器建立 session，curl 取不到內容，故以瀏覽器逐頁擷取 81 個法規類別後合併去重（原始結果存於 `tools/letters.json`）
- **未收錄**：工程／財物／勞務採購契約範本、投標須知範本——僅提供檔案下載且隨採購類型分版，未納入

再執行 `python gen.py` 重新產生 `data.js`。
