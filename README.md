# 政府採購法令彙編 · 學習索引網站

## 開啟方式
- 線上版：<https://yuan-5149.github.io/gov-procurement-law-index/>
- 雙擊 `index.html`（需 data.js、app.js、letters.js 在同資料夾）
- 或使用 `政府採購法令彙編-單檔版.html`（全部內嵌，可單獨複製到隨身碟或手機）
- `圖解總表.html`：九張流程圖的單頁版，可直接列印（每張圖不會被切斷）

### 每個畫面都有自己的網址
可以把「押標金那一條」直接貼給同事，重新整理也會留在原地，手機按上一頁會回上一層：

| 網址 | 內容 |
|---|---|
| `#/law/A0030057/50` | 政府採購法第 50 條 |
| `#/cat/b` | 貳 招標 |
| `#/search/押標金` | 搜尋「押標金」 |
| `#/plan/d30` | 30 天讀書計畫 |
| `#/quiz`、`#/exam`、`#/calc` | 自我測驗、模擬考、試算 |
| `#/letters/22` | 採購法第 22 條的工程會函釋 |

### 裝到手機上、離線也能用
線上版是 PWA：用手機瀏覽器開啟後選「加到主畫面」，就會像 App 一樣有圖示、全螢幕，
且在**沒有網路時仍可查全部條文與做題**（Service Worker 會把條文、題庫與函釋索引存在裝置上）。

## 功能

### 搜尋
- **關鍵字**：跨全部法規全文比對，命中標黃，結果依法規分組
- **多關鍵字**：空白分隔即 AND，如 `異議 申訴 期限`
- **條號直達**：輸入 `50`、`第50條`，列出各法規同條號條文
- **範圍限縮**：全部法規／本法規／本分類／★我的重點
- 快捷鍵：`Ctrl+K` 或 `/` 聚焦、`Esc` 清除

### 其他
- **條文互連**：條文中「本法第○條」（含中文數字）自動變成真正的連結——可用鍵盤 Tab 移動、
  也可按住 Ctrl／⌘ 在新分頁開啟；每條下方「相關條文」列出**反向引用**
- **標記重點**：條文右上 ☆，存於瀏覽器 localStorage；可作為搜尋與測驗範圍
- **學習紀錄可備份**：首頁「你的學習紀錄」可把標記、錯題本、複習排程、讀書計畫進度
  匯出成一個 JSON 檔，換手機或清除瀏覽資料後再匯入即可接續。紀錄只存在自己的瀏覽器，不會上傳
- 深／淺色主題、列印友善、手機版、ASCII 表格式條文以等寬字橫向捲動呈現
- 手機版：搜尋框獨佔一行（不再被工具列擠成一顆圖示），測驗的題型與範圍改為單行橫向捲動

## 資料來源與注意事項

- **法律與法規命令**：全國法規資料庫（法務部）`law.moj.gov.tw`
- **工程會行政規則**：行政院公共工程委員會主管法規共用系統 `lawweb.pcc.gov.tw`
- 兩者皆為擷取當日之現行有效版本，擷取日期見網站首頁
- **速記卡、概念比較、GPA 導讀、選擇題為學習用整理與自製練習題**，非法規原文亦非官方考古題；金額與期限請以最新法規及主管機關公告為準
- **已排除**：已廢止或停止適用之法規（採購文件保存作業準則、機關辦理工程委託專案管理廠商評選及計費辦法、採購履約爭議調解暨收費規則等）
- **函頒文件**：「政府採購錯誤行為態樣」取自政府電子採購網解釋函令系統之 113.12.05 函附件（.docx），以 `tools/planpe_dl.py` ＋ `tools/docx_read.py` 抓取解析
- **錯誤行為態樣家族**：工程會共函頒 13 份，其中 5 份具文字層已收錄；**§22各款執行錯誤態樣、評分及格最低標、共同供應契約缺失態樣之附件為掃描影像 PDF**，此環境無 OCR 故未收錄；最有利標與統包兩份實為「作業手冊」而非態樣表，性質不同未納入
- **解釋函令**：僅收錄**索引**（主旨摘要、發文日期與字號、對應條號），不含全文；主旨在來源即為節錄，過長者於 100 字截斷。該系統需瀏覽器建立 session，curl 取不到內容，故以瀏覽器逐頁擷取 81 個法規類別後合併去重（原始結果存於 `tools/letters.json`）
- **未收錄**：工程／財物／勞務採購契約範本、投標須知範本——僅提供檔案下載且隨採購類型分版，未納入

### 法規是否修正，每月自動檢查
`.github/workflows/check-law-updates.yml` 每月 1 日會執行 `tools/check_updates.py`，
逐部比對站上記錄的修正日期與來源網站的現行版本，發現有更新就自動開（或更新）一張
`law-update` 標籤的 issue，列出哪幾部法規需要重新擷取。也可以在 Actions 頁面手動觸發，
每次執行的結果摘要會顯示在該次 run 的頁面上。

> **工程會法規在 GitHub 上驗不到。** 全國法規資料庫（43 部）從 GitHub 的美國機房連線正常，
> 但工程會主管法規系統 `lawweb.pcc.gov.tw` 的 47 部會連線逾時（推測限制國外連線）。
> 排程檢查因此只涵蓋全國法規資料庫的部分，摘要會明白標示有幾部「來源站無回應」。
> 要完整比對全部 90 部，請在台灣本機執行：
>
> ```bash
> python tools/check_updates.py
> ```
