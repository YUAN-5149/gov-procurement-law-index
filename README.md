## 功能

### 搜尋
- **關鍵字**：跨全部法規全文比對，命中標黃，結果依法規分組
- **多關鍵字**：空白分隔即 AND，如 `異議 申訴 期限`
- **條號直達**：輸入 `50`、`第50條`，列出各法規同條號條文
- **範圍限縮**：全部法規／本法規／本分類／★我的重點
- 快捷鍵：`Ctrl+K` 或 `/` 聚焦、`Esc` 清除

### 四個記憶工具
| 工具 | 內容 |
|---|---|
| **重點速記卡** | 16 張高頻考點整併表（金額級距、招標方式、§22 十六款分群、等標期、決標比減價、押標金保證金、驗收期限、監辦、爭議流程、異議申訴期限、§101×§103、罰則、轉包分包、倫理迴避、未達公告金額招標、GPA） |
| **易混淆概念比較** | 12 組並排比較表（三種招標方式、異議/申訴/調解/仲裁、轉包/分包、四種保證金、廢標/不予開標/不決標/撤銷決標、初驗/驗收/部分驗收/減價收受、統包/共同投標/複數決標/共同供應契約、§12 vs §13 監辦、最低標 vs 最有利標、五個小組、誰要適用採購法、三種對廠商的不利處分） |
| **母法／細則對照表** | 由程式自動解析「本法第○條」引用關係產生；另列未被明文引用之母法條文 |
| **自我測驗** | **215 題選擇題**（四選一，附詳解與條文連結）＋ 條號翻牌卡兩種模式；可依分類或「★我的重點」限定題庫，即時計分與正確率 |

### 其他
- **條文互連**：條文中「本法第○條」（含中文數字）自動變連結；每條下方「相關條文」列出**反向引用**
- **標記重點**：條文右上 ☆，存於瀏覽器 localStorage；可作為搜尋與測驗範圍
- 深／淺色主題、列印友善、手機版、ASCII 表格式條文以等寬字橫向捲動呈現

## 資料來源與注意事項

- **法律與法規命令**：全國法規資料庫（法務部）`law.moj.gov.tw`
- **工程會行政規則**：行政院公共工程委員會主管法規共用系統 `lawweb.pcc.gov.tw`
- 兩者皆為擷取當日之現行有效版本，擷取日期見網站首頁
- **速記卡、概念比較、GPA 導讀、選擇題為學習用整理與自製練習題**，非法規原文亦非官方考古題；金額與期限請以最新法規及主管機關公告為準
- **已排除**：已廢止或停止適用之法規（採購文件保存作業準則、機關辦理工程委託專案管理廠商評選及計費辦法、採購履約爭議調解暨收費規則等）
- **未收錄**：「採購契約要項」及工程／財物／勞務採購契約範本、投標須知範本、政府採購錯誤行為態樣——這些係以**函頒**方式發布，不在上述兩個法規資料庫中

## 重新擷取最新條文

`tools/` 內含全部擷取與產生腳本：

| 檔案 | 用途 |
|---|---|
| `parse.py` | 解析全國法規資料庫 `LawAll.aspx` 頁面 |
| `pcc_parse.py` | 解析工程會 `LawContent.aspx` 頁面 |
| `content_compare.py` | 概念比較表內容 |
| `content_quiz.py` | 215 題選擇題題庫 |
| `gen.py` | 彙整全部來源，產生 `data.js` |
| `slavelist.json` / `pcc_list.json` | 兩個來源的法規清單（含代碼、名稱、日期） |

更新流程：把 `law.moj.gov.tw/LawClass/LawAll.aspx?pcode=<代碼>` 與
`lawweb.pcc.gov.tw/LawContent.aspx?id=<FL代碼>` 的頁面下載為 `raw_<代碼>.html` / `pcc_<FL代碼>.html`，
再執行 `python gen.py` 重新產生 `data.js`。
